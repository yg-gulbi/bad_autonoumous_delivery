# 복도 기본값을 바꾼 사본에서 옛 설정 호환 테스트 실패

bad_ws PART 03 · 2026-11-19 · 해결

## 1. 확인한 문제

`fleet.yaml`의 복도 모드를 `SHARED_YIELD`로 바꾼 임시 사본에서 테스트 46을 검증하자 350개가 통과하고 옛 설정 호환 테스트 1개가 실패했다. 누락된 모드를 복원한 결과는 `DIRECTIONAL`이었고 테스트의 기대값은 `SHARED_YIELD`였다.

## 2. 원인과 수정

테스트가 모드 키를 삭제한 입력을 읽은 뒤 결과 전체를 현재 YAML의 복도 설정과 비교했다. 모드가 생략된 파일의 정책은 현재 파일에 명시된 모드와 독립적이다. 예전 파일의 기본값인 방향별 공유와 양보 거리·시간을 직접 검사하도록 고쳤다.

## 3. 검증

저장소 원본과 두 사본에서 각각 실행했다. `DIRECTIONAL`, `SHARED_YIELD`, `EXCLUSIVE` 모두 PART 01·03 테스트 352개가 통과했다. [단계 4F 보고서](../ui/stage4f-report.md)
