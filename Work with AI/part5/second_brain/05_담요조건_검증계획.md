# 05. 담요 조건 검증 계획

## 1. 확인 결과

- 오늘 데이터셋은 요청대로 Roboflow Bed Exit v4에 고정했다.
- Roboflow의 세 클래스에는 담요 상태가 없으며 검수 20장에도 관절을 덮는 담요 조건이 없다.
- 현재 Pose·MediaPipe POC로 담요 강건성을 주장할 수 없다.

## 2. 오늘 수행하지 않은 변경

- SLP·BlanketSet 다운로드 및 병합 없음
- RGB-D·압력 데이터 생성 또는 변환 없음
- pseudo-depth 생성 없음
- 담요 조건 성능 수치 추정 없음

## 3. 후속 검증 분리

- RGB-only: 실제 RGB frame만 사용해 현재 네 방법을 비교한다.
- RGB-D: 실제로 시간 정렬된 depth가 있는 경우에만 별도 track으로 평가한다.
- 압력: 실제 pressure map이 있는 경우에만 별도 track으로 평가한다.
- RGB에서 만든 pseudo-depth는 시각적 탐색에 쓰더라도 성능·안전성 근거에서 제외한다.

담요 때문에 pose를 검출하지 못한 frame은 정상 `False`로 바꾸지 않는다. 현재 안전 정책과 같이 `JudgmentUnavailable`로 처리하고 5-frame 이력을 초기화한다.

## 4. 남은 의사결정

보충 데이터셋 라이선스, 담요 가림 단계 정의, modality별 합격 기준, 피험자·세션 단위 분할은 실제 후속 실험 전에 팀 승인이 필요하다. 임의 임계값은 만들지 않았다.

상세 검증 행렬과 기록 필드는 `src/part5_bed_exit/research/BLANKET_VALIDATION_PLAN.md`에 기록했다.
