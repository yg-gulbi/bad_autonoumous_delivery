# 10. 공개 병상 포즈·담요 데이터셋

## 선정 범위

일반 COCO·MPII 등 병상과 무관한 범용 포즈 데이터는 제외했다. 실제 병상 RGB 포즈를 포함하거나 담요 가림 조건을 포함하며, 공식 출처에서 현재 접근 가능한 자료만 대상으로 삼았다.

## 데이터셋별 의미

### Mannequin RGB In-Bed Pose

- 실제 병실 침대에서 촬영한 마네킹 RGB 312장
- 896×1600 해상도
- LSP 14관절 `joints_gt.mat` 제공
- 담요 없음
- 용도: 비가림 병상에서 YOLO Pose·MediaPipe 관절 위치 기초 평가

### SLP MICCAI19 공개 부분집합

- `simLab/00004/RGB/cover2`의 실제 두꺼운 담요 RGB 45장
- 896×1600 해상도, 단일 피험자
- RGB 이미지는 암호 없이 공개됐지만 `joints_gt_RGB.mat`은 암호화됨
- 용도: 관절 정확도가 아닌 검출 성공률·confidence·가시 관절 수·ROI 판정 정성 평가

### BlanketSet

- 실제 병원 병상, RGB·IR·Depth, 405개 영상과 8개 동작 조건
- 무담요·하반신 담요·전신 담요 조건
- 관절 정답 없음
- 2026-11-16 기준 원본 영상은 법적 사유로 접근 제한
- 공개 다운로드 가능 범위: README, 405행 조건표 CSV, 동작 설명 PNG

### BlanketGen2-Fit3D

- Fit3D에 합성하기 위한 1,217,312개 투명 담요 레이어
- `videos.zip` 약 29.8 GB, 보충자료 약 38 MB
- 원본 Fit3D RGB와 관절 라벨은 포함하지 않음
- 용도: 별도 Fit3D 라이선스 확보 후 담요 가림 학습 증강
- `preview`는 보충자료만, `full`은 보충자료와 `videos.zip`을 받음

### FallVision Pose Preview

- 병상 Fall/No-Fall RGB 영상과 pose CSV
- pose CSV는 YOLOv7 Pose 자동 추정값이며 수동 ground truth가 아님
- 용도: 파이프라인 형식·시간축 처리 검증; YOLO 관절 정확도 정답으로 사용 금지

## 실행 명령

```bash
PYTHONPATH=src/part5_bed_exit .venv/bin/python \
  src/part5_bed_exit/research/datasets/download_public_pose_blanket.py --list

PYTHONPATH=src/part5_bed_exit .venv/bin/python \
  src/part5_bed_exit/research/datasets/download_public_pose_blanket.py \
  --dataset mannequin_rgb_in_bed

PYTHONPATH=src/part5_bed_exit .venv/bin/python \
  src/part5_bed_exit/research/datasets/download_public_pose_blanket.py \
  --dataset slp_miccai19_public

PYTHONPATH=src/part5_bed_exit .venv/bin/python \
  src/part5_bed_exit/research/datasets/download_public_pose_blanket.py \
  --dataset blanketset_metadata

PYTHONPATH=src/part5_bed_exit .venv/bin/python \
  src/part5_bed_exit/research/datasets/download_public_pose_blanket.py \
  --dataset blanketgen2_fit3d --mode preview

# 약 29.8 GB를 내려받으므로 10 GiB 여유 공간을 보존할 수 있을 때만 실행된다.
PYTHONPATH=src/part5_bed_exit .venv/bin/python \
  src/part5_bed_exit/research/datasets/download_public_pose_blanket.py \
  --dataset blanketgen2_fit3d --mode full

PYTHONPATH=src/part5_bed_exit .venv/bin/python \
  src/part5_bed_exit/research/datasets/download_public_pose_blanket.py \
  --dataset fallvision_pose_preview
```

스크립트는 한 번에 한 데이터셋만 받는다. 접근 제한 영상, 암호화된 관절 라벨, 별도 라이선스 동의가 필요한 Fit3D 원본은 자동으로 받지 않는다. 다운로드 결과와 상태는 각 출력 디렉터리의 `download_manifest.json`·`status.json`에 기록한다.

## 2026-11-16 현재 확보 상태

- Mannequin RGB: 312장과 LSP14 라벨 확보·검증 완료
- SLP MICCAI19: `cover2` RGB 45장 확보, 전부 896×1600 디코딩 성공
- BlanketSet: 공개 README·405행 조건표·동작 이미지 확보; 원본 영상은 접근 제한
- BlanketGen2-Fit3D: 38,151,323-byte 보충자료 ZIP과 전체 파일 inventory 확보; 29.8 GB `videos.zip`은 `--mode full` 명령으로 별도 실행
- FallVision: 다운로드 명령 준비; pose CSV가 모델 생성 라벨이므로 정답 관절 평가에서는 제외
