## 2. 모듈 테스트 과정

첫 `colcon build`는 성공했다. 첫 `colcon test`는 pytest 테스트를 찾지 못하고 `unittest`를 실행해 0건·종료 코드 5가 발생했다.

검토한 변경:

1. `tests_require=['pytest']`: 현재 setuptools에서 unknown option으로 무시되어 실패
2. 명령의 `--python-testing pytest`: 임시 우회이므로 보류
3. `extras_require={'test': ['pytest']}`: setuptools와 colcon 모두 인식하여 채택

최종 결과:

```text
colcon build: 1 package finished
colcon test: 60 passed
colcon test-result: 60 tests, 0 errors, 0 failures, 0 skipped
pip check: No broken requirements found
```

문제·실패 시도·원인·수정·검증은 `docs/troubleshooting/2026-11-16-part5-colcon-pytest-discovery.md`에 복구 가능하게 기록했다.
