# 모델별 이미지 추론 실험 결과

두 정적 이미지와 인위적 하체 가림 입력에서 사람 검출·관절 추정·영상 복원 결과를 비교했다. **원본 정답 라벨이 없으므로 아래 수치는 정확도가 아닌 모델 출력 지표이다.**

## 실험 입력과 기준

| 항목 | 내용 |
| --- | --- |
| 비가림 이미지 | [01_uncovered_slp.jpg](../../../test_images/01_uncovered_slp.jpg): 이불 없이 누운 장면 |
| 이불 가림 이미지 | [02_covered_arm_out_slp.jpg](../../../test_images/02_covered_arm_out_slp.jpg): 이불을 덮고 팔 일부가 드러난 장면 |
| 인위적 가림 입력 | `01_uncovered_masked_lower`: 비가림 이미지의 하체를 인위적으로 가린 조건 |
| 원본 출처·정답 | 저장소에서 확인되지 않음. 파일명의 `slp`만으로 출처 확정 불가 |
| 침대 ROI | 이미지별 `.roi.json`에 저장된 침대 영역 좌표. 정답 라벨이 아님 |
| 관절 수 기준 | 신뢰도 **0.3 이상**. 전체 17개, 하체 6개 기준 |
| 수치 기준 | 아래 관절 수·신뢰도는 GPU(CUDA) 기록 기준. 시간은 반올림 |

## 1. 사람 검출·세그멘테이션

| 모델 | 처리 방식 | 비가림 결과 | 이불 가림 결과 | 한계 |
| --- | --- | --- | --- | --- |
| YOLO11n | 사람 박스와 침대 ROI의 위치 비교 | 검출 신뢰도 0.87, ROI 밖 0.4%, `SAFE` | 검출 신뢰도 0.54, ROI 밖 0%, `SAFE` | 가림 시 박스가 머리·상체 중심으로 축소됨 |
| YOLO11n-seg | 사람 마스크의 침대 ROI 밖 비율 계산 | 검출 신뢰도 0.85, ROI 밖 0%, `SAFE` | 검출 신뢰도 0.59, ROI 밖 0%, `SAFE` | 검출된 마스크만으로 이불 아래 신체 위치를 확인할 수 없음 |

`SAFE(False)`는 현재 코드의 판정이며 원본 정답이 아니다. 위 수치는 [팀 공유 기록](../../../research/TEAM_SHARE_2026-11-16.md)의 단일 프레임 실험을 기준으로 한다.

## 2. 관절 추정 모델

| 모델 구성 | 입력 영역 | 비가림 관절 수 | 이불 가림 관절 수 | 이불 가림 하체 평균 신뢰도 | GPU 시간 / 이미지 |
| --- | --- | ---: | ---: | ---: | ---: |
| YOLO11n-pose | 모델 자체 사람 검출 | 전체 17/17, 하체 6/6 | 전체 7/17, 하체 0/6 | 0.019 | 7.4~7.7ms |
| YOLO11n + ViTPose-Base-Simple | YOLO 사람 박스 | 전체 17/17, 하체 6/6 | 전체 9/17, 하체 0/6 | 0.097 | 25~27ms |
| YOLO11n + ViTPose-Base | YOLO 사람 박스 | 전체 17/17, 하체 6/6 | 전체 10/17, 하체 0/6 | 0.107 | 25~27ms |

비가림 이미지의 전체 관절 평균 신뢰도는 YOLO Pose 0.936, ViTPose-Base-Simple 0.928, ViTPose-Base 0.941이었다. **이불 가림 이미지에서는 세 구성 모두 하체 관절이 기준 미만이었다.** ViTPose 구성에서도 사람 검출 박스가 상체로 축소되어 하체 정보가 제한되었다.

## 3. 복원 모델 + ViTPose-Base

복원 후 **YOLO 사람 박스**를 사용하는 방식과 **침대 전체 ROI**를 사용하는 방식을 구분했다. 아래 관절 수 역시 신뢰도 0.3 이상 기준이다.

| 복원 모델 | ViTPose 입력 영역 | 인위적 하체 가림: 전체 / 하체 | 이불 가림: 전체 / 하체 | 이불 가림 하체 평균 신뢰도 |
| --- | --- | --- | --- | ---: |
| AOT-GAN | YOLO 사람 박스 | 13/17 · 2/6 | 사람 검출 실패 | — |
| AOT-GAN | 침대 전체 ROI | 17/17 · 6/6 | 16/17 · 6/6 | 0.679 |
| MAE-Base 프로토타입 | YOLO 사람 박스 | 13/17 · 2/6 | 11/17 · 1/6 | 0.140 |
| MAE-Base 프로토타입 | 침대 전체 ROI | 17/17 · 6/6 | 15/17 · 6/6 | 0.620 |

| 비교 항목 | 저장된 관찰 결과 |
| --- | --- |
| AOT-GAN 복원 전후 | 인위적 가림 + 사람 박스 조건에서 하체 관절 수는 2개로 동일. 하체 평균 신뢰도는 0.269 → 0.285 |
| AOT-GAN + 전체 ROI | 인위적 가림 입력의 하체 평균 신뢰도 0.705. 신뢰도 0.5 이상 관절은 전체 15개, 하체 4개 |
| MAE + 전체 ROI | 인위적 가림 입력의 하체 평균 신뢰도 0.812. 전체 17개 관절이 신뢰도 0.5 이상 |
| MAE + 사람 박스 | 이불 가림 입력에서 신뢰도 0.5 이상 하체 관절은 0개 |
| 이불 가림 + 전체 ROI | AOT-GAN과 MAE 모두 전체 15개 관절이 신뢰도 0.5 이상 |

## 결과 해석과 검증 범위

| 항목 | 현재 확인된 내용 |
| --- | --- |
| 가림의 영향 | 이불 가림 시 사람 박스가 상체로 축소되고, 박스 기반 관절 추정에서 하체 신뢰도가 낮아짐 |
| 전체 ROI의 영향 | 더 많은 관절이 높은 신뢰도로 출력됨. 실제 관절 위치와의 일치 여부는 미검증 |
| 복원 효과 분리 | 복원 없이 동일한 전체 ROI를 사용하는 대조 결과가 확인되지 않아 복원 자체의 기여를 분리하기 어려움 |
| 복원 관절의 의미 | 생성된 신체와 높은 관절 신뢰도가 실제 숨겨진 자세의 복원을 보장하지 않음 |
| ROI의 `bbox_conf=1.0` | 직접 지정한 입력 영역의 값이며, 사람 검출 모델의 확신도 100%를 의미하지 않음 |
| 처리 시간 비교 | 실행 조건·초기화 비용 등이 다를 수 있어 통제된 속도 벤치마크가 아님 |
| 재현성 | 복원 실험의 생성 스크립트·정확한 마스크 및 복원 설정은 추가 확인 필요 |
| 미검증 범위 | 정답 대비 관절 오차, 실제 이탈 장면 검출 성능, 연속 영상의 5프레임 다수결 성능 |
| 단일 프레임 평가 | `research/evaluation/single_frame_comparison.py`에서 `judge(frame)`를 직접 호출하며 다수결 미적용 |
| 운영 판정 정책 | 5프레임 중 3회 이상 이탈 시 판정하는 정책과 별도로 해석해야 함 |
