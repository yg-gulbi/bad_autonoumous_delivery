# 데이터셋별 모델 벤치마크

폴더 이름이 시험 입력과 대응한다.

- `roboflow_bed_exit_106_images/`: Roboflow 침대 이탈 106장
- `roboflow_pose_20_images/`: Roboflow Pose 20장
- `slp_cover2_45_images/`: SLP Cover2 45장
- `slp_pose_pair_2_images/`: SLP 비가림·가림 2장
- `coco_in_bed_7_images/`: COCO 병상 장면 7장
- `blanket_conditions_62_samples/`: 담요 조건 62개 샘플

`summary.json`은 실험 요약, `results.csv` 또는 이름이 유사한 CSV는 샘플별 결과,
`panels/`·contact sheet는 모델 출력 시각화다.
