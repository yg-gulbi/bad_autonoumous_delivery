# SLP 공식 공개 샘플

출처: https://github.com/ostadabbas/SLP-Dataset-and-Code/tree/master/imgs

공식 저장소의 `00091_00001.gif`, `00091_00016.gif`, `00091_00031.gif`를 다운로드했다. PNG는 각 GIF의 처음·중간·마지막 프레임을 추출한 미리보기이며, `preview.jpg`는 이를 모은 이미지다.

이 파일들은 공개 데모 자료이며, 정답 라벨이 포함된 원본 데이터셋 샘플로 취급하지 않는다. 별도의 정답 annotation은 다운로드하지 않았다. 프레임 번호는 GIF 내부 순서이며 자세·가림 조건 라벨이 아니다. 원본 전체 데이터 접근 및 이용 조건은 공식 저장소와 연결된 SLP 안내를 확인한다.

`*_rgb_preview.png`는 첫 프레임의 왼쪽 RGB 패널을 잘라낸 저해상도 미리보기이다. `preview.jpg`는 GIF별 첫 프레임 3개를 모았다.
