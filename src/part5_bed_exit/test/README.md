# Part 5 테스트 인덱스

테스트 코드는 검증 대상 커밋의 짧은 해시별로 분리한다.

- `0dc450f_v1_1/`: `feat/part5-imsohy` 마지막 커밋 기준 기존 테스트
- `64e57ce_v1_2/`: `part5-refactoring` 커밋의 현재 모듈을 직접 검증하는 테스트
- `80805b4_v1_3/`: 런타임 메서드 로딩 복구 후 단위·통합·벤치마크 검증
- `1e0faac_v1_4/`: 비동기 반복 TTS·전체 파라미터화·프레임/ROI 회전·선택적 다중 모델 앙상블 검증

`80805b4_v1_3/integration/`은 외부 자식 클래스 로딩과 실제 MP4 경로를 검증하고,
`80805b4_v1_3/integration_benchmark/`는 런타임 로더 기반 벤치마크를 검증한다.
v1.3.2처럼 공개 계약을 유지하는 patch 변경의 회귀 테스트도 같은 `v1_3` 아래에 추가한다.
내부 리팩터링 후에도 기존 `integration/`과 `integration_benchmark/` 코드는 수정 없이
재실행할 수 있어야 한다.

v1.3 테스트를 개별 실행하는 명령과 Python 선택 규칙은
[`80805b4_v1_3/README.md`](80805b4_v1_3/README.md)를 따른다.
